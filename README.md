# KnifeshopBackendConfigurations

Dokumentation der Konfigurationen im Admin-Bereich des Staging-Onlineshops, die am Live-System nachgezogen werden müssen.

---

## Plugins

### Deaktivierte Plugins

Die folgenden unnötigen Plugins wurden im Staging-System deaktiviert und müssen auch im Live-System deaktiviert werden:

| Plugin-Schlüssel | Beschreibung |
|------------------|--------------|
| `language-advanced` | Sprachverwaltung (erweitert) |
| `marketplace` | Marketplace-Funktion |
| `mollie` | Mollie Payment Gateway |
| `paystack` | Paystack Payment Gateway |
| `razorpay` | Razorpay Payment Gateway |
| `sale-popup` | Sales-Popup |
| `shippo` | Shippo Versandintegration |
| `social-login` | Social Media Login |
| `sslcommerz` | SslCommerz Payment Gateway |
| `stripe-connect` | Stripe Connect |
